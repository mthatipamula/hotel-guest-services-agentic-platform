How can the agents help?

Describe a guest situation. The triage router picks the right specialists (12 in-process, 7 remote over A2A), they work in parallel with hotel data through MCP, and high-impact actions wait for your approval.

Agent trace

Send a request to see the plan, every agent call (local or A2A), tool calls via MCP, governance decisions, guardrails and token usage.

Human-in-the-loop approvals

Agents can only propose room moves, folio credits and late checkouts. Nothing changes in the hotel system until a manager approves here. The MCP tool re-checks tier limits and room status on execution.

Agent registry

Every agent registers here: in-process agents by the orchestrator, remote agents by publishing an A2A Agent Card that the registry fetches and verifies. Governance policies decide tools, callers, token budgets and which guest data an agent may receive. Suspend is a live kill switch.

MCP registry

Tool servers agents discover at runtime instead of hard-coding URLs.

Token management

Per-request budget, per-agent daily budgets (from governance), model tiering (flash-lite for routing and safety, flash for specialists, pro for the judge), composer skipped for single-agent answers, truncated tool outputs and cached policy search.
